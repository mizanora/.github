## HijriAnchor

HijriAnchor brings Umm al-Qura Hijri and Gregorian dates together for everyday planning. It offers calendar conversion, events and reminders, with core calendar calculations and saved events available offline.

Visit [the official website](https://mizanoraapp.com) for current product information, downloads, privacy details and support.
